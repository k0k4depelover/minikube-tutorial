Instalación de Minikube en Arch Linux

Guía paso a paso para configurar tu clúster local de pruebas con Docker y kubectl.

Requisitos Previos

Asegúrate de que tu procesador soporte virtualización ejecutando:

grep -E --color 'vmx|svm' /proc/cpuinfo

Si la salida muestra coincidencias en texto coloreado, la virtualización por hardware está habilitada.

01

Instalar el Driver (Docker)

Minikube necesita un hipervisor o gestor de contenedores. En Arch Linux, Docker es la opción más sencilla y recomendada:

sudo pacman -S docker
sudo systemctl enable --now docker.service
sudo usermod -aG docker $USER
Importante: Cierra sesión y vuelve a iniciarla (o ejecuta newgrp docker) para aplicar los permisos de grupo sin necesidad de usar sudo.
02

Instalar Minikube y Kubectl

Tanto minikube como kubectl están disponibles en los repositorios oficiales de Arch Linux:

sudo pacman -S minikube kubectl

Opcionalmente, puedes activar el autocompletado en tu terminal (Bash):

echo 'source <(kubectl completion bash)>' >> ~/.bashrc
echo 'source <(minikube completion bash)>' >> ~/.bashrc
source ~/.bashrc
03

Iniciar el Clúster

Inicia Minikube especificando Docker como el controlador por defecto:

minikube start --driver=docker

Para dejar Docker configurado como driver predeterminado para futuras sesiones:

minikube config set driver docker
04

Verificar el Estado

Comprueba que los nodos y componentes del clúster estén en estado Ready:

minikube status
kubectl get nodes
05

Desplegar una Web Estática (Opcional)

Para probar que todo funciona, crea un despliegue de Nginx y expón su servicio en el clúster:

kubectl create deployment web-demo --image=nginx
kubectl expose deployment web-demo --type=NodePort --port=80
minikube service web-demo

El último comando abrirá automáticamente tu navegador apuntando a la IP y puerto expuestos.
